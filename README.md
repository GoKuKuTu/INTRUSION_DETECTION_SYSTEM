# 🛡️ Adaptive AI-Based Intrusion Detection System
### Machine Learning & Deep Learning for Real-Time Network Security

---

## 📌 Overview

This project implements a **real-time Intrusion Detection System (IDS)** using a hybrid approach that combines **Machine Learning (ML)** and **Deep Learning (DL)** models.  

The system introduces an **adaptive model selection mechanism** that dynamically chooses the most suitable model based on the **complexity of network traffic**, ensuring both **high accuracy** and **efficient performance**.

---

## 🎯 Key Features

- 🔍 Real-time network traffic monitoring  
- 🤖 Hybrid ML + DL detection system  
- 🧠 Adaptive model selection based on complexity score  
- ⚡ Fast and efficient processing  
- 📊 Confidence score for predictions  
- 🌐 API-based architecture (FastAPI + Node.js)  
- 🐳 Docker support for deployment  

---

## 🧠 Core Innovation

> **Adaptive Model Selection Mechanism**

Instead of using a single model, the system:
- Uses **Machine Learning** for simple traffic (fast & efficient)  
- Uses **Deep Learning** for complex/suspicious traffic (high accuracy)
